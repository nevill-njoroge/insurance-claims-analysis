# Insurance Claims Analysis | Python + Excel

Cleaned 5,000+ insurance claim records and built a loss-ratio dashboard.

## What I Did
- Removed duplicates and missing values in Python (Pandas)
- Calculated loss ratio by age group and policy type
- Built Excel dashboard with pivot tables + charts
- Delivered 1-page summary of top claim drivers

## Tools
Python, Pandas, Excel (Pivot Tables, XLOOKUP, Charts)

## Files
- clean_claims.py - Python cleaning script
- claims_dashboard.xlsx - Excel dashboard
- claims_cleaned.csv - Cleaned dataset
